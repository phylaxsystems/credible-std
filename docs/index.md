# Credible Standard Library

Solidity standard library for writing Credible Layer assertions. Inspect transaction state,
register triggers, and test invariants with the contracts and interfaces in this API reference.

## Start here

- [Assertion](../src/Assertion.sol): base contract and trigger registration.
- [PhEvm](../src/PhEvm.sol): transaction-state inspection and assertion precompiles.
- [CredibleTest](../src/CredibleTest.sol): test assertions locally.
- [Credible Layer documentation](https://docs.phylax.systems/credible/credible-introduction): concepts and guides.
- [Repository README](../README.md): installation, examples, and development instructions.

Browse the sidebar for protection suites, protocol interfaces, and utility contracts.
